# NumsBoss

NumsBoss is a simple command-line tool written in Go that converts numbers between decimal and binary formats.

## Features

- Convert decimal numbers to binary
- Convert binary numbers to decimal
- Interactive menu for easy operation
- Input validation

## How to Run

```bash
go run main.go
```

## How to Use

1. Run the program using the command above
2. When prompted "What types of numbers do you convert:", type one of the following:
   - `Decimal` - to convert a decimal number to binary
   - `Binary` - to convert a binary number to decimal
   - `Exit` - to quit the program
3. Enter the number when prompted
4. The converted result will be displayed
